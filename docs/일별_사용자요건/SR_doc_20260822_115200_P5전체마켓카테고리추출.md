## 반영 내용

### 1. 마켓 5종 추가 (총 6종)

스크린샷에서 확인한 행 ID·마켓 코드·표기를 그대로 등록했다.

| 코드 | 표기 | 화면 행 | 스크린샷 |
|------|------|---------|----------|
| `AUC20` | 옥션2.0 | `tr#mapping_category_AUC20` | (앞 요건) |
| `11ST` | 11번가 | `tr#mapping_category_11ST` | 1·6 |
| `GMK20` | G마켓2.0 | `tr#mapping_category_GMK20` | 2·7 |
| `SMART` | 스마트스토어 | `tr#mapping_category_SMART` | 3·8 |
| `COUP` | 쿠팡 | `tr#mapping_category_COUP` | 4·9 |
| `LTON` | 롯데ON | `tr#mapping_category_LTON` | 5·10 |

각 마켓의 [전체카테고리] 버튼은 동일 패턴이라 코드만 바꿔 그대로 잡는다.

```html
<a class="defbtn_med dtype6"
   onclick="search_category('11ST','openmarket_category_search_list_11ST','allview');">
  <span>전체카테고리</span></a>
```

### 2. 목록 select 두 벌 대응 (중요)

스크린샷 6·10 에서 확인한 대로, 마켓에 따라 select 이 두 개 있고 **보이는 쪽이 다르다.**

- 11번가: `list_11ST` 가 `display:none`, `list2_11ST` 가 표시
- 롯데ON: `list2_LTON` 가 `display:none`, `list_LTON` 가 표시

그래서 두 id 를 모두 읽어 **항목이 많은 쪽**을 사용한다 (`list_select_ids`).

### 3. 전체 마켓 일괄 추출

`--market ALL` — 6개 마켓을 순서대로 [전체카테고리] 조회해 **한 엑셀**에 모은다.
`마켓` 열로 구분되고, 마켓별 행수를 로그에 남긴다. 파일명은
`카테고리분류표_전체마켓_<날짜_시각>.xlsx`. 중간에 [작업중단] 하면 그 지점까지 저장한다.

보드 P5 탭 마켓 리스트박스 맨 위에 **전체 마켓 일괄 (ALL)** 항목을 추가했다
(기본 선택은 옥션2.0).

### 4. 기타

- 대기 예산(`T_LIST`)을 호출 시점에 읽도록 바꿔 테스트·조정이 가능해졌다.
