## 반영 내용

탐색을 시작하기 전에 **후보를 규칙으로 먼저 좁힌다**(`matching.constrain`). 좁힌 뒤에
기존 순서(1 단계일치 → 2-1~2-4 → 3 최근접)를 그대로 태운다. 규칙이 후보를 모두
지워버리면 그 규칙은 적용하지 않는다(빈손 방지).

| 규칙 | 구현 | 비고 |
|------|------|------|
| 1. 엑셀 범위 | 확정 후 `is_from` 검사, 벗어나면 `ensure_from` 으로 교정 | v2.4.1 |
| 2. 성별 고정 | 같은 성별(남성/여성/공용/아동) 경로만 남김. 같은 성별이 없으면 **무성별** 경로만 (다른 성별 배제) | `gender_paths` |
| 3. 품목명 일치 | 의류·잡화·모자·선글라스·액세서리·신발 중 필터명에 있는 명칭이 든 경로만, **품목명이 나오는 단계가 얕을수록 우선**(상위→중위→하위) | `item_paths` · `item_level` |
| 4. 의류 우선 | 패션의류잡화 → 패션의류 → 남성패션의류 → 여성패션의류 → 남성의류 → 여성의류 순으로 먼저 걸리는 그룹만 남김 | `clothing_priority` |

요건 예시대로 동작한다.

```
아름트리-무신사-남성-의류-팬츠
  후보: 패션의류 > 남성 > 하의 > 팬츠 / 스포츠/레저 > 등산 > 등산바지
  → 패션의류 > 남성 > 하의 > 팬츠   [2-1) 상위 → 중위 → 하위 · 성별=남성 · 품목=의류]

아름트리-무신사-여성-모자-비니 → 패션의류잡화 > 여성 > 모자 > 비니 (남성 경로 배제)
```

적용된 규칙은 로그 단계 표기 뒤에 `[성별=남성 · 품목=의류]` 로 남는다.
