## 반영 내용

### 1. 작업표시줄 고정 (원문 1 · v1.6.2)

`board/desktop_icon.py` 가 바탕화면 아이콘 생성 후 고정까지 시도한다.

- 핀 폴더 복사: `%APPDATA%\Microsoft\Internet Explorer\Quick Launch\User Pinned\TaskBar`
- 셸 verb 호출: 「작업 표시줄에 고정」 / `Pin to taskbar`
- 시작메뉴 등록: Windows 가 자동고정을 막을 때 우클릭으로 고정하도록
- 결과를 메시지로 구분 안내, `--no-pin` 으로 고정 없이 아이콘만 생성

### 2. 아이콘 실행 시 자동 반영 (원문 2 · v1.7.0)

`board/auto_update.py` 신설. `run.bat`(=바탕화면 아이콘)이 보드 시작 전에 호출한다.

| 단계 | 동작 |
|------|------|
| 버전 비교 | 로컬 `VERSION.txt` vs 원격 — **더 높을 때만** 갱신 |
| 원격 선택 | 독립 repo `Mango_Helper_AI_Board` 우선 → 없으면 부모 repo `main` 의 `Mango_Helper_AI_Board/` |
| 갱신 방법 | `.git` 이 있으면(자기 폴더 또는 상위 저장소) `git pull`, 없으면 GitHub ZIP 에서 해당 폴더 파일만 덮어쓰기 |
| 실패 시 | 오프라인·다운로드 실패여도 **막지 않고 현재 버전으로 실행** |
| 생략 | `run.bat --noupdate` · 확인만 `board\auto_update.py --check` |

보호 대상(덮지 않음): `run-logs` · `output` · `.chrome-profile` · `*.xlsx` ·
`.translate_options.json` · `.site_options.json` · `*.lnk` · `*.log`.

이로써 "버전이 그대로"인 문제가 사라진다 — PC 폴더에 `.git` 이 없어도 아이콘만
누르면 최신본이 반영된다.

### 3. 변수명 정정 (원문 3)

독립성 테스트의 예외 허용 목록 이름 `AI_BOARD_NAME_ALLOWED` →
**`NAME_MENTION_ALLOWED`**. 코드에 부모 저장소 이름이 남는 곳은 자동갱신 폴백
URL(`PARENT_REPO`) 과 이름 구분 상수(`terms.py`) 뿐이며, 원격 URL 외의 용도로는
쓰이지 않는지 검사하는 테스트를 추가했다
(`test_auto_update_only_uses_ai_board_as_remote_url`).

독립 저장소에 소스를 올리면(`scripts\publish-standalone.ps1`) 부모 폴백 자체가
불필요해진다.
