## 반영 내용

### 신설 폴더 `P5_카테고리_엑셀추출/`

| 파일 | 내용 |
|------|------|
| `extract_categories.py` | 본체 (파싱·엑셀·화면조작) |
| `run.bat` · `__init__.py` · `README.md` | 실행·패키지·설명 |
| `tests/test_extract_categories.py` | 단위테스트 17건 |

### 화면 조작 (스크린샷 1~4 DOM 그대로)

| 단계 | 근거 |
|------|------|
| 마켓 행 | `tr#mapping_category_AUC20` · 라벨 「옥션2.0 카테고리」 (1번 샷) |
| 전체카테고리 | `<a onclick="search_category('AUC20','openmarket_category_search_list_AUC20','allview');"><span>전체카테고리</span></a>` (2번 샷) |
| 목록 리스트박스 | `select#openmarket_category_search_list_AUC20` (3번 샷) |
| 옵션 텍스트 | `e쿠폰/모바일상품권 > 교육/어학이용권 > 온라인교육/외국어` … (4번 샷) |

버튼을 못 찾으면 `search_category(마켓, ...,'allview')` 를 직접 호출하는 폴백이 있고,
ajax 로 채워지는 목록은 옵션이 실제로 늘어날 때까지 최대 15초 기다린다(채워지면 즉시).

### 카테고리분류표 양식

`>` 로 쪼개 1~6단계 열에 배치한다.

| 마켓 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 | 6단계 | 전체경로 |
|------|-------|-------|-------|-------|-------|-------|----------|
| 옥션2.0 | e쿠폰/모바일상품권 | 교육/어학이용권 | 온라인교육/외국어 | | | | (원문 경로) |

- 안내 옵션(`- 카테고리를 선택해주세요 -`)·중복 경로 제외
- 6단계보다 깊으면 나머지를 6단계에 합쳐 양식 유지, 최대 깊이를 로그에 표기
- 저장 위치: `output\카테고리분류표_<마켓>_<날짜_시각>.xlsx` (헤더 고정·열폭·틀고정 적용)

### 마켓 선택

`AUC20`(옥션2.0, 기본) · `GMK20`(지마켓2.0) · `11ST` · `IPST` · `WMP`.
같은 화면의 다른 마켓 행도 코드만 바꿔 그대로 추출한다.

### 보드 · 실행 경로

- 보드 **P5_카테고리_엑셀추출** 탭 — 마켓 리스트박스 · 접근 URL · 저장경로 ·
  [추출 시작] · [작업중단] · **[엑셀 열기]** · 실행로그
- `programs/registry.json` `p5_category` · `scripts/launch/P5_카테고리엑셀추출.bat`
- CLI: `python extract_categories.py --market GMK20 --out D:\out\분류표.xlsx`
- `--from-text 목록.txt` — 브라우저 없이 목록 텍스트만으로 엑셀 생성 (검증·재작업용)
