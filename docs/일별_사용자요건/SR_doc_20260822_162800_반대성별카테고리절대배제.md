## 반영 내용

기존에는 "같은 성별이 있으면 그쪽 우선" 이라 규칙이 약했다. 이제 **후보 자체에서
반대 성별을 제거**한다.

| 위치 | 처리 |
|------|------|
| 탐색 시작 | `strip_opposite_gender()` — 여성 필터면 `남성*` 전부, 남성 필터면 `여성*` 전부 제거 |
| 1·2-x·3 단계 | 제거된 목록 위에서만 동작 (최근접 지정 포함) |
| 최종 선택 직전 | `violates_gender()` 재검사 → 위반이면 배제 후 재선정, 로그 `반대 성별 카테고리 배제 → 재선정` |
| 고를 것이 없을 때 | 매핑하지 않고 사유 기록 — `성별(여성) 조건에 맞는 카테고리 없음` |

마지막 항목은 "반드시 하나 지정" 요건과 충돌하는 지점인데, **성별 절대 배제를
우선**했다. 잘못된 성별 카테고리로 저장되는 쪽이 더 위험하기 때문이다.
