파이썬이 아닌 파일은 보조 역할이다.

- `*.bat`(17) · `*.ps1`(4): 더블클릭 실행·PC 설치 래퍼 — Windows 셸이어야 하는 부분

  규격이 JS. 파이썬(Playwright)이 이 확장을 띄워서 사용한다

결론: **로직은 파이썬, 실행 편의는 배치, 브라우저 확장만 JS.**
이 내용을 `README.md` 「구성 — 순수 파이썬 프로그램」 절에 기록했다.

## 원문 2 반영 — 바탕화면 실행 아이콘

요청대로 **아이콘 생성도 파이썬으로** 구현했다 (표준 라이브러리만).

| 파일 | 역할 |
|------|------|
| `board/desktop_icon.py` | 바탕화면 탐색·검증·로그·아이콘 생성 (신규) |
| `망고보드_바탕화면아이콘.bat` | 더블클릭 래퍼 (신규) |
| `board/app.py` | 좌측 하단 **[바탕화면 아이콘 만들기]** 버튼 추가 |
| `programs/registry.json` | `desktop_icon` 프로그램 등록 |
| `scripts/launch.py` | `.ps1`·`.bat` 등록 프로그램도 실행되게 확장자별 분기 |
| `.gitignore` | 생성물 `*.lnk` 제외 |

동작:

- 바탕화면 `망고보드.lnk` → `run.bat` (작업 폴더 = 망고보드 루트)
- **OneDrive 바탕화면**·한글 **「바탕 화면」** 폴더까지 모두 찾아 각각 생성
- 프로젝트 폴더에도 사본 1개 — 바탕화면 생성이 막힌 PC 는 드래그로 해결
- 아이콘: `imageres.dll,171` (AI보드 아이콘 `109` 과 구분), 없으면 `shell32.dll,44`
- 작업표시줄 고정은 우클릭 → [작업표시줄에 고정] 안내 (프로그램 자동 고정은
  Windows 가 막아둔 동작이라 시도하지 않음)

기술 선택 이유: `.lnk` 는 Windows 셸 전용 포맷이라 저장만 `WScript.Shell` COM 에
위임했다. 이때 PowerShell 을 **`-EncodedCommand`(UTF-16LE)** 로 호출해 한글 경로·
파일명이 코드페이지 때문에 깨지는 문제를 원천 차단했다 (기존 `setup-pc.ps1` 은
UTF-8 no-BOM 한글이라 PS 5.1 에서 깨질 수 있었다).

검증: `board/tests/test_desktop_icon.py` 11건 — 바탕화면 후보 수집·중복 제거,
`.lnk` 경로 구성, PowerShell 스크립트 내용(run.bat·아이콘·따옴표 이스케이프),
`-EncodedCommand` 왕복 디코딩, run.bat 없음·비Windows 예외 처리, registry 등록,
`launch.py` 확장자 분기. 총 `board/tests` 18건 통과.

※ 앞 커밋(망고보드 가져오기)에 이 기능 파일이 함께 담겼고, 버전 표기는 1.4.4 이다.
