## 반영 내용

### 신설 `matching.py` — 탐색 전담 모듈

기존 토큰 유사도 방식은 **보조**로 내리고, 요건의 순서를 그대로 구현했다.

#### 필터명 해석

| 조각 | 규칙 |
|------|------|
| 무시 | `-` 로 나눈 앞 **2조각** (아름트리-무신사) |
| 상위 | 3번째 조각 + 보조 후보 `패션잡화` · `의류잡화` · `패션의류잡화` |
| 중위 | 4번째 조각 + 동의어 (`소품` ↔ `잡화`) |
| 하위 | 나머지를 전개 — 붙인말 · 각 토큰 · 반쪽 |

요건 예시 그대로 나온다.

```
버킷/사파리 햇 → 버킷햇 · 버킷 · 햇 · 사파리
바라클라바     → 바라클라바 · 바라 · 클라바
선글라스/안경테 → 선글라스 · 안경테
```

#### 찾는 순서

| 단계 | 동작 |
|------|------|
| 1 | 망고 단계수 == 엑셀 단계수 → 상위·중위·하위를 단계 순서대로 대조 |
| 2-1 | 상위 목록(없으면 중위 목록) → 중위로 좁힘(없으면 하위) → 하위에서 선택 |
| 2-2 | 중위 이름으로 **전체** 재검색 |
| 2-3 | 하위 이름으로 **전체** 재검색 |
| 2-4 | 품목별 포괄 — 의류/신발/잡화 구분해 지정 카테고리에서 검색 |

동점이면 **일치 조각이 많고 경로가 짧은** 쪽을 고른다. 끝내 못 찾으면 그 마켓은
건너뛰어 오매핑을 막는다. 어느 단계에서 찾았는지는 실행로그와 `--dry-run` 에
`[2-1) 상위 → 중위 → 하위]` 형태로 남는다.

### 확인 (요건 예시 3건)

```
아름트리-무신사-남성-모자-버킷/사파리 햇 → 패션의류잡화 > 남성 > 모자 > 버킷햇
아름트리-무신사-남성-모자-바라클라바     → 패션의류잡화 > 남성 > 모자 > 바라클라바
아름트리-무신사-남성-소품-선글라스/안경테 → 패션의류잡화 > 남성 > 소품 > 선글라스
```
