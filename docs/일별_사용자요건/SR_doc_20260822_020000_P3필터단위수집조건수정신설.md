## 반영 내용

### 1. 프로그램 신설 (P2_필터단위_상품수변경 복제)

`P3_필터단위_수집조건수정/` — 이름은 원문 2 대로 **P3** 로 반영.

| 파일 | 내용 |
|------|------|
| `update_collect_option.py` | 본체 — 필터 행 순차: 수집조건수정 → 번역옵션 적용 → 저장하기 → 확인 |
| `run.bat` · `__init__.py` · `README.md` | 실행·패키지·설명 |
| `tests/test_update_collect_option.py` | 단위테스트 18건 |

행 순회·수정화면 진입·저장·확인은 복제 원본과 동일하게 `P3_필터_갱신` 헬퍼를
재사용한다(`list_demango_rows` · `click_edit_on_row` · `wait_modify_page` ·
`click_save_button` · `click_modified_confirm` · `_return_to_list`). 중단 플래그는
이 프로그램 전용 `.option_stop` 이다.

### 2. 입력 필드 = 리스트박스 (원문 1-1, 원문 3)

스크린샷 3번의 목록을 **순서 그대로** 기본값으로 넣었다.

```
번역안함
더망고 무료 번역기 사용
구글 번역기 사용
DeepL 번역기 사용
네이버(클라우드) 번역기 사용
```

보드 탭 `P3_필터단위_수집조건수정` — 숫자 입력칸 대신 **Listbox**(스크롤 포함) +
선택값 표시 라벨 + **[망고에서 옵션 읽기]** 버튼. 읽어온 목록은
`.translate_options.json` 에 캐시되어 다음 실행 때 그대로 뜬다.

### 3. 선택값을 망고에 적용 (원문 1-2, 스크린샷 1·2)

스크린샷의 실제 DOM 을 1순위 선택자로 썼다.

```html
<tr height="30" id="layer_tr_limit_count">
  <td align="center" bgcolor="#F1EEEE">번역 후 저장</td>
  <td bgcolor="#FFFFFF">
    <select name="translate_method" onchange="trans_change(this.value);"> …
```

- 1순위: `select[name="translate_method"]` — 옵션 텍스트·value 를 함께 읽음
- 폴백: 「번역 후 저장 / 번역옵션 / 번역」 라벨 주변의 select · 라디오 · 체크박스
  (화면이 바뀌어도 동작하도록)
- 적용은 **라벨 기준 선택**(`select_option(label=…)`) — 실패 시 같은 인덱스의
  option value 로 재시도. `onchange="trans_change(this.value)"` 는 이 선택으로
  정상 발생한다
- 적용 직후 **선택 라벨을 다시 읽어 검증** (`options[selectedIndex].text`).
  value 가 아니라 라벨로 비교하므로 `0/1/2` 같은 내부값에 속지 않는다
- 리스트박스 선택값 매칭은 정확 일치 → 공백무시 → 부분포함 순서라
  「구글」·「DeepL」 처럼 일부만 골라도 맞는 옵션을 찾는다

### 4. 등록·실행 경로

- `programs/registry.json` — `p3_option` 항목 (보드탭 `p3_option`)
- `scripts/launch/P3_수집조건수정.bat` · `py -3 scripts\launch.py p3_option`
- CLI: `python update_collect_option.py --translate-option "구글 번역기 사용"`,
  목록만 확인은 `--list-options` (출력 `##OPTION##<옵션명>`)
