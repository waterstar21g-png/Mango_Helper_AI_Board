## 1. GUI 화면에 "국내 / 해외 구분" 입력필드 신설 (요건 2)
* `board/app.py` 의 P5_101 설정 영역 첫 번째 줄("상품수집사이트" 콤보박스 우측)에 `구분 [●국내 ○해외]` 라디오버튼 배치.
* 작업 실행 시 `map_categories.py --region-type 국내` (또는 `해외`) 파라미터로 자동 전달 연동.

## 2. 절대 배제 단어 카테고리 필터링 엔진 구축 (요건 3, 후속 1·2·3)
* `matching.py` 에 `FORBIDDEN_BASE_WORDS` 정의:
  - 브랜드, 여행, 티켓, 스포츠, 등산, 낚시, 배낭
  - 유아, 아동, 유아동, 영유아, 키즈, 주니어, 베이비, 남아, 여아
  - 운동, 여가
  - 중성, 혼용, 공용, 유니섹스, 남녀
  - 골프, 안전, 구기, 꽃, 생필품, 배달음식, 배달, 생활용품, 수입명품, 가구, DIY, PC, 주변기기, 가공식품, 식품
* **예외 규칙**: "망고 필터명"에 명백히 해당 단어가 포함되어 있는 경우(예: `남성-골프-골프웨어`, `남성-스포츠-트레이닝팬츠` 등)는 배제 대상에서 제외하고 정상 매핑 허용 (`forbidden_words_for()`).

## 3. "국내 / 해외" 구분에 따른 지역별 카테고리 매핑 규칙 적용 (요건 4, 5 및 후속 2·3)
* `OVERSEAS_WORDS` 목록에 `해외`, `역직구`, `해외직구`, `해외의류`, `해외배송`, `해외패션`, `해외쇼핑`, `수입`, `수입명품`, `병행수입`, `직구` 포함.
* **입력값이 "국내"인 경우**: "해외", "수입명품", "수입" 등 단어가 들어간 카테고리를 후보군에서 완전히 배제 (`filter_by_region(..., '국내')`).
* **입력값이 "해외"인 경우**: "해외", "수입" 관련 단어가 들어간 카테고리에 최하위 우선순위(대폭 감점)를 부여하여, 국내/일반 카테고리 대안이 없을 때만 최후의 수단으로 선택되도록 우선순위 재정의 (`priority_rank(..., region_type='해외')`).

## 4. 마켓별 "미매핑" 종료 로직 완전 삭제 및 100% 매핑 완주 보장 (요건 1)
