## 반영 내용

### 1. 수집사이트 musinsa.com 한정

`ALLOWED_SITES = ("musinsa.com",)` · 기본값 `MUSINSA.com`. 다른 사이트를 넣으면
실행 전에 막는다.

- CLI: `수집사이트 제한: 현재는 musinsa.com 만 수행합니다 (요청=…)` 로 종료
- 보드: 경고창 「현재는 musinsa.com 만 수행합니다 … 검증이 끝나면 다른 사이트도
  열겠습니다」 후 실행하지 않음
- 입력칸 옆에 `※ 현재는 musinsa.com 만 수행 (검증 후 확대)` 상시 표기

### 2. 작업 대상 = 검색 결과 목록

[선택조건으로 검색하기] 를 누른 **뒤 화면**에서 행을 읽고, 그중 체크된 행만
처리한다 (기존 동작을 요건에 맞춰 로그로 명시).

### 3. 작업 행 범위 [부터] ~ [까지]

`작업행 갯수` 대신 **범위 지정**으로 바꿨다.

| 항목 | 값 |
|------|-----|
| 기본값 | **1 부터 5 까지** |
| 규칙 | 1부터 세고 **양끝 포함**. 뒤집혀 있으면(9~2) 자동으로 바로잡음. 0·음수·빈값은 기본값 |
| 로그 | `체크된 행 N건 중 **a~b행** → m건 수행`, 행마다 `[i/m] (전체 k행)` |
| 범위 밖 | `작업 범위(a~b)에 해당하는 행이 없습니다` 로 종료 |

- 보드 P5_101 탭: `작업 행 범위 [ 1 ] 부터 [ 5 ] 까지` 두 칸
- CLI: `--row-from 6 --row-to 10`
