## 반영 내용

### 1. 3회 추가 시도 (원문 1)

`map_one_market` 이 실패(검색 결과 없음 · 목록 선택 실패)하면 **직전 후보를 제외**하고
다른 카테고리로 다시 시도한다. 최대 **3회**(`MAP_RETRIES`). 3회 후에도 안 되면 그
마켓만 실패로 두고, 행 끝에서 **[검색필터 설정저장 (Alt+S)]** 을 눌러 마무리한다.

### 2. 최근접 카테고리 반드시 지정 (원문 2)

규칙 탐색(1 · 2-1~2-4) 이 모두 실패하면 **빈손으로 끝내지 않는다.** 새 단계
`3) 최근접 지정` 이 필터명을 종합 해석해 가장 가까운 카테고리 하나를 고른다.

| 신호 | 사용 방식 |
|------|-----------|
| 이름 | 하위·중위 조각과 카테고리 리프/경로의 **글자(bigram) 유사도** |
| 성별 | 남성·여성·공용·아동 — 일치 가점, **불일치 감점** |
| 소재·재료 | 가죽·레더·니트·데님·면·울·린넨·퍼·메쉬·고어텍스 … 경로에 있으면 가점 |
| 용도·활용 | 등산·캠핑·스포츠·러닝·골프·웨딩·방한·레인 … 경로에 있으면 가점 |
| 품목 성격 | 의류/신발/잡화 포괄 카테고리에 가점 |

동점이면 경로가 짧은(상위 개념) 쪽을 고른다. 로그에는 `[3) 최근접 지정 (0.42)]` 로
남아 어떤 근거로 골랐는지 구분된다. 기존처럼 "미검출"이 필요하면
`find_category(..., force=False)` 를 쓴다.
