## 반영 내용

### 신설 `P5_101_카테고리매핑_필터세부설정/`

| 파일 | 내용 |
|------|------|
| `map_categories.py` | 본체 (엑셀 로드 · 매칭 · 화면 조작) |
| `run.bat` · `__init__.py` · `README.md` | 실행·패키지·설명 |
| `tests/test_map_categories.py` | 단위테스트 25건 |

### 초기 1회

| 단계 | 구현 |
|------|------|
| 상품수집사이트 | `select[name="site_id"]` 라벨/값 선택 |
| 선택조건으로 검색하기 | `a[onclick*="search_filter('search')"]` |
| 마켓별 카테고리 자료 | 엑셀 폴더에서 **파일명으로 마켓 자동 인식** 후 메모리 보관. P5 출력 양식(전체경로/1~6단계) 모두 지원 |

### 1단계 루프 (체크된 행)

`table#search_category` 를 훑어 체크박스·`market_mapping_new('<ftid>')`·필터이름을 읽고,
행마다 [설정수정] → 팝업(`admin_category_set.php?tm=F&ps_ftid=<ftid>`) →
[AI 자동 매핑 시작하기](`search_recommend_category_all`) → 마켓 루프 →
[검색필터 설정저장](`config_save`) → 모달 닫기 → 다음 행. 팝업 클릭이 막히면 팝업 URL 을
직접 열고, 저장 버튼이 없으면 Alt+S 로 대체한다.

### 2단계 루프 (마켓별) — 원문 2·3 반영

| 마켓 | 입력필드 | 결과 리스트박스 |
|------|----------|-----------------|
| 옥션2.0 | `#openmarket_category_search_text_AUC20` | `#openmarket_category_search_list_AUC20` |
| 11번가 | `…_11ST` | `…list_11ST` / **`…list2_11ST`** |
| G마켓2.0 | `…_GMK20` | `…list_GMK20` |
| 스마트스토어 | `…_SMART` | `…list_SMART` |
| 쿠팡 | `…_COUP` | `…list_COUP` |
| 롯데ON | `…_LTON` | `…list_LTON` / **`…list2_LTON`** |

11번가·롯데ON 은 결과 리스트박스도 두 벌이라 **보이는 select 을 우선** 읽고 그 select 에서
선택한다 (P5 에서 겪은 것과 같은 구조).

검색 버튼은 `search_category('<코드>','openmarket_category_search_list_<코드>','')`.

### 최적 카테고리 선정

필터이름과 카테고리 경로를 토큰으로 쪼개 겹침 비율을 계산하고, 마지막 단계(리프)에
가중치를 준다. 부분 포함(`남성비니` ↔ `비니`)에 보너스. 점수가 **0.34 미만이면 매핑하지
않고 건너뛴다** — 엉뚱한 카테고리가 저장되는 것을 막기 위해서다. 검색어는 리프만 넣고,
결과 목록에서는 완전일치 → 리프일치 → 최고 유사도 순으로 고른다.

`--dry-run "필터이름1,필터이름2"` 로 브라우저 없이 매칭 결과만 확인할 수 있다.
