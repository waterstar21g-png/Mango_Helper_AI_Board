## 반영 내용

행 번호는 화면의 **[설정수정]**(`onclick="market_mapping_new(...)"`) 링크가
위에서부터 몇 번째로 나오는지로 정해진다 — 즉 표를 시각적으로 위→아래 세는 것과
같다. 이 대응 관계를 **매핑 없이 미리 확인**할 수 있게 했다.

| 방법 | 사용 |
|------|------|
| CLI | `python map_categories.py --list-rows --row-from 11 --row-to 11` |
| 보드 | P5_101 탭 **[행 목록 확인]** 버튼 |

출력은 1행부터 번호·ftid·필터명을 나열하고, 지정한 작업 행 범위에 `★` 를 붙인다.

```
검색 결과 782행 (위에서부터 1행)
    10행: ftid=770 · 필터=아름트리-무신사-남성-모자-캡
★ 11행: ftid=782 · 필터=아름트리-무신사-여성-신발-샌들/슬리퍼
    12행: ftid=790 · 필터=아름트리-무신사-여성-신발-부츠
```

이걸로 스크린샷의 11행(ftid=782, 샌들/슬리퍼)이 실제 매핑 대상과 일치하는지
매핑 실행 전에 확인할 수 있다.
