## 반영 내용

### 1. 구분 라디오 (스크린샷 DOM 그대로)

```html
<label>
  <input type="radio" name="openmarket_seller_type2_11ST" value="1"
    onclick="change_category_list('openmarket_category_search_list_11ST',
             'openmarket_category_search_list2_11ST','1020804',
             'openmarket_cm_category_11ST','11ST', this);" checked>
  <span id="openmarket_seller_type2_text1">해외카테고리</span>
</label>
```

| 마켓 | 구분 | 비고 |
|------|------|------|
| 11번가 (`11ST`) | 해외카테고리 / 국내카테고리 | 화면 안내 「11번가는 해외/국내카테고리가 다릅니다」 |
| 롯데ON (`LTON`) | 해외직구 카테고리 / 일반카테고리(=국내) | 화면 안내 「롯데온은 일반/해외직구 카테고리가 다릅니다」 |

라디오는 같은 `label` 안의 `span` 텍스트로 찾는다 (id 는 두 마켓이 동일하게
`openmarket_seller_type2_1/2` 라서 name + 라벨로 특정). 클릭 후
`change_category_list(...)` 가 목록 select 을 교체하므로 0.4초 대기한 뒤
[전체카테고리] 를 누른다. 라디오를 못 찾으면 그 구분만 실패로 남기고 진행한다.

### 2. 각각 추출 → 엑셀 `구분` 열

`마켓 × 구분` 조합을 순서대로 돌려 **두 목록을 모두** 담는다. 엑셀 열 구성이 바뀌었다.

| 마켓 | 구분 | 1단계 | … | 6단계 | 전체경로 |
|------|------|-------|---|-------|----------|
| 11번가 | 해외카테고리 | … | | | |
| 11번가 | 국내카테고리 | … | | | |
| 롯데ON | 해외직구 카테고리 | … | | | |
| 롯데ON | 일반카테고리 | … | | | |

구분이 없는 마켓(옥션2.0·G마켓2.0·스마트스토어·쿠팡)은 `구분` 이 빈 값이고 동작은
이전과 같다. 실행로그에는 조합별 행수를 남긴다 (`11번가 국내카테고리: N행`).
