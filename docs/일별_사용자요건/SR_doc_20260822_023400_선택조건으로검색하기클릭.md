## 반영 내용

버튼 라벨이 **[선택조건으로 검색하기]** 임을 확인해, 이 라벨을 1순위 선택자로
클릭하도록 바꿨다 (`click_search`).

| 순위 | 대상 |
|------|------|
| 1 | 라벨 `선택조건으로 검색하기` 를 가진 `a`·`button`·`input` (`@value` 포함) |
| 2 | 같은 라벨의 `span` (앵커 내부 span 클릭) |
| 3 | 검색줄 `span.bt_type` 내부 버튼 (폴백) |
| 4 | `검색` 이 들어간 버튼 (폴백) |
| 5 | `input[name="sch_keyword"]` 에 Enter (폴백) |

실행로그에 어느 경로로 눌렸는지 남긴다 —
`[선택조건으로 검색하기] 클릭` / `검색 버튼 클릭(폴백)` / `검색 실행(키워드칸 Enter)`.
