## 답변 · 반영 내용

아이콘을 만드는 **코드·스크립트는 이미 완료(v1.4.4)** 되어 있고, PC 바탕화면에
실제로 놓는 것은 파일이 PC로 내려간 뒤 한 번 실행하는 단계다.

PC 절차 (머지 후):

1. 바탕화면 「AI_보드_버전갱신」 1회 → `Mango_Helper_AI_Board/` 폴더가 내려옴
2. 그 폴더의 `망고보드_바탕화면아이콘.bat` 더블클릭 → 바탕화면에 **[망고보드]** 생성
   (또는 망고보드 실행 후 좌측 하단 **[바탕화면 아이콘 만들기]**)

점검 중 발견한 문제 — 바로가기 생성 구현이 **두 갈래**로 갈라져 있었다.
`scripts/install-all.ps1` · `scripts/setup-pc.ps1` 이 각자 `WScript.Shell` 로
`망고보드.lnk` 를 만들면서, 아이콘 지정도 없고 OneDrive·한글 「바탕 화면」 폴더도
빠뜨렸다. 설치 경로로 만든 아이콘과 새 아이콘이 서로 달라지는 문제다.

- 두 스크립트가 `board/desktop_icon.py` 를 호출하도록 통합 (자체 생성 코드 제거)
- 회귀 테스트 추가: 설치 스크립트에 `CreateShortcut` 이 남아 있으면 실패
  (`board/tests/test_desktop_icon.py` → `board/tests` 총 19건 통과)
