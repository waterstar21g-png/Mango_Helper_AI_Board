## 문제 재현

사용자가 직전에 제시한 실사례("여성-신발-구두" 검색 결과 6개 마켓 전부 오매핑:
유아동 여아구두, 무성별 신발잡화 등)를 코드로 그대로 재현해 근본 원인을
끝까지 추적했다. 사용자의 이번 지적("카테고리명 자체에 '여성'과 '구두'가
그대로 들어 있다")이 정확했고, 그런데도 왜 못 찾았는지 4가지 독립적인
버그가 겹쳐 있었다.

## 발견·수정한 버그 4건

1) **성인/아동 오분류**: "여아"를 성별 배제 목적으로 `GENDER_WORDS["여성"]`
   에 넣어둔 부작용으로, "여아"가 "여성"과 같은 성별로 인식돼 아동용
   카테고리("유아동신발 > 여아구두")가 성인 검색에서 전혀 배제되지 않았다.
   성별과 "성인/아동"은 서로 다른 축이라는 걸 깨닫고, `matching.py` 에
   `CHILD_WORDS`/`mentions_child()`/`is_child_category()` 를 독립적으로
   신설해, 필터명이 아동을 언급하지 않았는데 후보가 아동 카테고리면
   절대규칙으로 배제하도록 `map_categories.best_category_via_master` 에
   연결했다.

2) **복합어 계열 오판**: "정장구두"(하이힐/펌프스/정장구두)처럼 수식어
   ("정장"=의류)가 머리명사("구두"=신발)보다 앞에 오는 복합어를,
   `class_of()`의 "가장 먼저 걸리는 단어" 규칙이 통째로 "의류"로 오분류해
   신발 계열 검색에서 계열불일치로 배제시켰다. 두 계열 단어가 공백 없이
   바로 이어붙은 경우 뒤쪽(머리명사) 계열을 따르도록 수정.

3) **후보 목록 절단(limit)**: `category_master_db.resolve_ranked()` 를
   `limit=10`으로 호출해, 정답 후보가 13번째 순위라 애초에 목록에 들어오지
   못했다(쿠팡 "구두" 사례). `limit=50`으로 늘렸다.

4) **동점 시 무성별 우선**: 글자 유사도(bigram overlap)가 0으로 동점일 때
   경로 길이만으로 순위를 매겨, 성별 표기가 전혀 없는 밋밋한 대분류
   ("신발")가 성별이 명시된 더 구체적인 후보("여성단화")를 이겼다.
   `_direct_name_matches()`·`_similar_candidates()` 둘 다 `gender` 인자를
   받아 동점 시 같은 성별이 명시된 경로를 우선하도록 수정.

부가로 `best_category_via_master()` 의 검색어 순회 순서(하위→중위) 로직도
"더 구체적인 검색어의 4단계 강제지정"이 "덜 구체적인 검색어의 확실매칭"
보다 우선하도록 재구성했고, "구두주걱"(신발 도구)을 비제품 힌트 단어에
추가했다.
