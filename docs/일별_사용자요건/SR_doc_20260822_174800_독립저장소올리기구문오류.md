## 반영 내용

### 원인

`scripts/*.ps1` 이 **BOM 없는 UTF-8** 로 저장돼 있었다. Windows PowerShell 5.1 은
BOM 이 없는 `.ps1` 을 시스템 ANSI 코드페이지로 읽는데, 한글 Windows 는 CP949 다.
CP949 디코더는 `0x81~0xFE` 를 2바이트 문자의 첫 바이트로 보고 다음 바이트를 함께
소비하므로, UTF-8 로 저장된 한글·기호가 뒤따르는 문자까지 삼킨다.

`publish-standalone.ps1` 83행이 그 경우다.

```
Write-Host "  ※ GitHub 저장소 기본 브랜치가 main 이 아니면" -ForegroundColor DarkGray
```

CP949 로 읽으면 문장 끝 큰따옴표가 삼켜져 문자열이 닫히지 않고, 다음 줄들이 그
문자열 안으로 빨려 들어간다. 그래서 85행 `} else {` 에서 `Unexpected token '}'` 가
났다. 파일 전체로는 따옴표 60개 중 **2개**가 사라진다.

`install-all.ps1` 도 같은 결함이 있었다 (따옴표 150개 중 2개 소실). 아직 오류를
만나지 않았을 뿐이다.
