## 반영 내용

탐색 로직은 원래 엑셀 목록에서만 고르지만, 요건대로 **보증 장치**를 넣었다.

| 항목 | 내용 |
|------|------|
| `matching.is_from(paths, cat)` | 고른 값이 엑셀 목록 안의 값인지 판정 (공백·대소문자 무시) |
| `matching.ensure_from(paths, cat, name)` | 범위 밖이면 목록 안 최근접 값으로 교정 |
| `_map_once` | 최적 카테고리 확정 직후 검사 → 교정 시 로그 `엑셀 범위 밖 → 목록 내 값으로 교정`, 단계 표기에 `· 엑셀범위 교정` 추가 |
| 로그 | `최적 카테고리(엑셀) = …` 로 출처를 명시 |
| 화면 목록 선택 | 사이트 검색 결과에서 항목을 고를 때 **엑셀 카테고리** 를 기준으로 맞춘다 (필터명 기준 아님) |
