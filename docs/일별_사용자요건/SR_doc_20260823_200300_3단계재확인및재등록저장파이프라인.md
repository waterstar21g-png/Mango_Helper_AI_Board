## 1. 미매핑 발생 원인 분석
화면 스크린샷(`admin_category_set.php?tm=F&ps_ftid=793`) 분석 결과:
1. **검색어 불일치**: 엑셀의 전체 경로(예: `패션의류잡화 > 남성패션 > 남성의류 > 티셔츠`)로 검색 시 화면 API에서 0건이 반환되는 경우, 2차 검색으로 이어지지 않고 멈추어 select 리스트박스가 빈 상태(`- 전송대상 마켓 카테고리를 선택해주세요 -`)로 남음.
2. **DOM / hidden 필드 미동기화**: select 박스에서 옵션을 선택하더라도 웹페이지의 `openmarket_cm_category_<코드>` 및 `openmarket_cm_category_name_<코드>` hidden 필드가 즉시 동기화되지 않고 저장되어 저장이 무효화됨.
3. **저장 후 상태 미확인**: 1회 저장 후 화면에 실제 남아있는 값을 검증하지 않고 팝업을 닫음.

## 2. '최초 -> 저장 -> 2차 확인/등록/저장 -> 3차 확인/등록/저장' 파이프라인 구현
`map_categories.map_one_row()` 에 사용자가 명시한 3단계 순차 파이프라인을 정확히 구축:
1. **1단계 (최초 등록 & 저장)**:
   - 6개 마켓에 대해 다단계 검색어(전체 경로 → 리프 단어 → 필터명 하위/중위어 → 품목어)로 옵션을 반드시 로드하고 선택.
   - `choose_option()` 에서 DOM change/input 이벤트 및 hidden 필드 강제 동기화 JS(`CHOOSE_OPTION_JS`) 실행.
   - 6개 마켓 매핑 후 **1차 저장 (Alt+S)** 수행.
2. **2단계 (확인 -> 누락 확인 -> 2차 등록 -> 저장)**:
   - 저장 후 `unmapped_markets()` 로 실제 화면의 hidden 필드 및 select 선택 상태를 재검증.
   - 누락(미매핑)된 마켓이 발견되면 해당 마켓에 대해 다른 검색어 및 안전 폴백으로 **2차 등록** 수행.
   - 2차 등록 완료 후 **2차 저장 (Alt+S)** 수행.
3. **3단계 (확인 -> 누락 확인 -> 3차 등록 -> 저장)**:
   - 2차 저장 후 다시 실제 화면 상태 재확인.
   - 여전히 누락된 마켓이 있으면 **3차 등록** 수행 후 **3차 저장 (Alt+S)** 수행.
4. **성별 재검증**:
   - 저장된 최종 이름이 반대 성별인지 검증하고 필요 시 재선정 및 재저장.
