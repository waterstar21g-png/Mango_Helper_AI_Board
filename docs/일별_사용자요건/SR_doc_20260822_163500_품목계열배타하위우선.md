## 반영 내용

### 1·2. 품목 계열 배타

계열 사전을 만들어 **다른 계열은 후보에서 제거**한다.

| 계열 | 대표어 |
|------|--------|
| 의류 | 의류·상의·하의·아우터·팬츠·티셔츠·니트·코트·원피스·스커트 |
| 신발 | 신발·슈즈·운동화·스니커즈·구두·부츠·샌들·슬리퍼 |
| 모자 | 모자·캡·비니·버킷햇·벙거지·방한모 |
| 선글라스 | 선글라스·안경·안경테·아이웨어 |
| 시계 | 시계·워치·손목시계 |
| 가방 | 가방·백팩·크로스백·토트백·지갑 |
| 액세서리 | 액세서리·주얼리·목걸이·귀걸이·반지·팔찌 |

의류 필터는 신발 경로를, 신발 필터는 의류 경로를, 선글라스 필터는 시계 경로를
고르지 않는다. 계열이 드러나지 않는 경로는 남긴다(정보 부족으로 배제하지 않음).

### 3. 잡화 폴백

같은 계열 경로가 하나도 없으면 **잡화 계열**(잡화·소품·패션잡화·의류잡화·패션의류잡화)
에서 고른다. 로그에는 `계열=신발→잡화폴백` 으로 남는다.

### 4. 검색 순서 — 하위 1차, 중위 2차

상위·중위·하위 순 좁히기(2-1)에서 결정하지 못하면

1. **하위 이름으로 전체 재검색** (동의어 확장 포함) — `2-2) 하위 전체`
2. **중위 이름으로 전체 재검색** — `2-3) 중위 전체`
3. 포괄(2-4) → 최근접(3)

이전에는 중위가 먼저였는데 요건대로 순서를 바꿨다. 망고 화면 검색어도 선정된
카테고리의 **하위(리프)** 를 넣는다.
