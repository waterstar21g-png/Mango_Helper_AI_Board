### 1. 필터명 정밀 분석 강화 (동의어)

표현이 달라 못 찾는 경우를 사전으로 메웠다. 리프가 동의어와 일치하면 높은 가중치를 준다.

| 필터명 표현 | 카테고리 표현 |
|-------------|---------------|
| 바라클라바 | 방한모 · 발라클라바 · 마스크모자 |
| 버킷햇 | 벙거지 · 사파리햇 |
| 비니 | 니트모자 · 털모자 · 방한모 |

| 선글라스 · 안경테 | 아이웨어 · 안경 |
| 스니커즈 | 운동화 · 캔버스화 |
| 목도리 | 머플러 · 스카프 |

기존 종합 판단(성별·소재·용도/활용·글자 유사도)과 함께 적용된다. 예:
`아름트리-무신사-남성-모자-바라클라바` + 엑셀에 `패션잡화 > 남성 > 방한모` 만 있어도
`[3) 최근접 지정 (0.75)]` 로 매핑된다.

### 2. 저장 후 재검증 — 6개 마켓 누락 방지

행의 마켓을 모두 매핑하고 **[검색필터 설정저장 (Alt+S)]** 을 누른 뒤, 화면의 hidden 값

```
#openmarket_cm_category_<코드>          (카테고리 코드)
input[name="openmarket_cm_category_name_<코드>"]   (카테고리명)
```

을 읽어 **실제 매핑 여부를 재검증**한다. 비어 있는 마켓이 있으면

1. 그 마켓만 다시 매핑하고
2. 다시 저장하고
3. 다시 검증 — **최대 3회**(`VERIFY_ROUNDS`)

3회 후에도 남으면 로그에 `경고: 재검증 3회 후에도 미매핑 — <마켓명>` 을 남기고 결과에
`unmapped` 로 기록한다. 실행로그에는 매 회차마다 `재검증 1/3 — 미매핑: 쿠팡 · 롯데ON`
형태로 남는다.
