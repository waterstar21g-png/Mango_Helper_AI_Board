## 반영 내용

### 신설 `P3_설정수정_카테고리매핑초기화/`

요건 1번대로 `P3_필터단위_수집조건수정` 을 복제했고, 목록·팝업 조작은
`P5_101_카테고리매핑_필터세부설정`(`map_categories.py`) 의 코드를 재사용했다.
두 프로그램이 같은 화면(목록 `admin_group.php`, `market_mapping_new` 팝업,
`admin_category_set.php`)을 다루므로 로직을 새로 만들 필요가 없고, 앞서 여러 차례
고친 안정판(행 스캔·프레임 탐색·행 번호 확인)을 그대로 물려받는다.

| 파일 | 내용 |
|------|------|
| `reset_category_mapping.py` | 본체 — `map_categories` import 해 재사용 |
| `run.bat` · `__init__.py` · `README.md` | 실행·패키지·설명 |
| `tests/test_reset_category_mapping.py` | 단위테스트 9건 |

### 입력 (요건 3번)

| 요건 | 구현 |
|------|------|
| 사이트명 | `--site-id` → `select[name="site_id"]` (비우면 화면 선택 유지) |
| 작업 URL | `--list-url` → 이동 후 **[선택조건으로 검색하기]** 자동 클릭 |
| 작업행 범위 [부터]-[까지] | `--row-from` · `--row-to` (1부터, 양끝 포함) |

### 동작 (요건 0~4번)

0. 작업 URL 이동 → 사이트명 선택 → **[선택조건으로 검색하기]**(`search_filter('search')`)
   클릭 → 결과 목록 조회
1. 행의 **[설정수정]**(`onclick="market_mapping_new('<ftid>')"`) 클릭 → 팝업
   (`admin_category_set.php?tm=F&ps_ftid=<ftid>`)
2. 팝업에서 **[검색필터 설정삭제]**(`onclick="config_remove('','Y')"`) 클릭
3. 팝업 닫기
4. 다음 행 반복 (행 범위 안에서 순차)

팝업 클릭이 막히면 팝업 URL 을 직접 열고, 삭제 버튼을 못 찾으면 `config_remove('','Y')`
를 직접 호출한다. 실패해도 팝업은 반드시 닫고 다음 행으로 넘어간다.

### 부가 — 몇 번째 행인지 확인

P5_101 의 `--list-rows`(행 목록 확인)를 그대로 물려받아, 초기화 없이 행 번호·ftid·
필터명을 먼저 확인할 수 있다.
