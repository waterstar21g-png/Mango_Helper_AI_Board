## 반영 내용

Cloud Agent(리눅스) 에서 망고보드를 바로 개발·실행할 수 있도록 개발환경을 정의했다.
망고보드는 순수 파이썬(tkinter UI + playwright 자동화)이므로 별도 서버가 없다.

### 추가 파일

| 파일 | 역할 |
|------|------|
| `.cursor/environment.json` | Cloud Agent 환경 정의 (`install` = 설치 스크립트 실행) |
| `scripts/cloud-agent-install.sh` | 멱등 설치 스크립트 (apt·pip·playwright) |

### 설치 단계 (`scripts/cloud-agent-install.sh`)

1. `sudo apt-get install -y python3-tk` — tkinter UI(`board/app.py`) 용 시스템 패키지
2. `pip install -r requirements.txt -r P2/requirements.txt pytest` — 파이썬 의존성
   (externally-managed 파이썬이라 `--break-system-packages` 사용)
3. `python3 -m playwright install chromium` — 자동화·테스트용 브라우저

### 기본 이미지

Cursor 기본 이미지(Node/Python 포함, Python 3.12) 를 그대로 사용한다. tkinter 를
제외한 브라우저 시스템 라이브러리는 기본 이미지에 이미 포함돼 있어 헤드리스
chromium 이 정상 구동된다. 별도 Dockerfile 은 불필요했다.

### 로그인 필요 프로그램 (P1~P5) 관련

P1~P5 자동화는 외부 사이트(더망고 / FitCL) 로그인 세션(Chrome CDP 9222)이 있어야
실제 동작한다. 이는 외부 계정이 필요한 부분이라 환경 셋업 검증 범위에서는 제외했고,
로그인 없이도 되는 통합 CLI·UI 기동·전체 테스트로 환경을 검증했다.
