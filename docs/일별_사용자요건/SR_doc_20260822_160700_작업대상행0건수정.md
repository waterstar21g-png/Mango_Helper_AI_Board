## 원인

행 스캔 JS 가 `table#search_category` **안쪽만** 훑도록 되어 있었다. 그 화면은
설정수정 링크가 그 테이블 바깥(중첩 표)에 있어서, 링크가 15개인데도 행은 0개로
읽혔다. 진단 로그가 이 불일치를 그대로 보여줬다 — `설정수정링크=15` 인데 결과 0행.

## 수정

1. **표 구조에 기대지 않는다.** `a[onclick*="market_mapping_new"]` 를 문서 전체에서
   찾고 `closest('tr')` 로 그 행을 거슬러 올라간다.
2. 필터이름은 ① 행 안의 텍스트 input 값 → ② `input[attr-uid="<ftid>"]` 값
   → ③ 행 첫 줄 순으로 읽는다 (화면에서 이름은
   `<input class="input_" value="아름트리-무신사-남성-모자-캡/야구모자" attr-uid="720">`).
3. 프레임이 여러 개면 결과를 **합치고 ftid 중복은 제거**한다 (진단상 프레임1·2에
   같은 행이 중복 노출됐다).
