## 반영 내용

### 신설 `market_cache.py`

마켓별 카테고리 **원본 경로**(엑셀을 읽은 결과)만 JSON으로 캐시한다.
`CATEGORY_MASTER`/`KEYWORD_DICTIONARY`처럼 그 위에서 파생한 색인·동의어
매핑은 캐시하지 않고 항상 이 원본에서 다시 계산한다 — 파생 결과를
그대로 캐시하면 `matching.py`의 동의어 사전이 나중에 바뀌어도 캐시가
낡은 값을 계속 돌려주는 사고가 나기 때문이다.

| 함수 | 역할 |
|------|------|
| `save(excels, path=None)` | 마켓별 카테고리 경로를 `data/market_categories_cache.json` 에 저장 |
| `load(path=None)` | 캐시를 읽어 마켓별 카테고리 경로로 되돌림 (없으면 `{}`) |
| `exists` / `stats` | 캐시 존재 여부·통계 확인 |

### 요건대로 "엑셀 있으면 갱신, 없으면 캐시 사용" 흐름 (원문 2)

- `load_market_excels()` — 엑셀을 성공적으로 읽으면(성공한 마켓이
  하나라도 있으면) **자동으로 캐시를 갱신**한다(`update_cache=True` 기본).
- `load_market_excels_or_cache(paths)` — 엑셀 경로가 주어지고 읽기에
  성공하면 그 결과(=최신)를 쓰고, **엑셀 경로가 없거나 전부 읽기 실패**
  하면 캐시(=직전에 구축해 둔 최신 자료)로 대체한다.
- `run_mapping()` 과 CLI(`main()`) 양쪽 진입점 모두 이 흐름으로 연결했다.

### 실제 캐시 구축·커밋 (원문 1)

로컬에 남아 있던 실제 6개 마켓 카테고리 엑셀(`P5_카테고리_엑셀추출/
output/*.xlsx`, 14,882개 카테고리 경로)을 그대로 읽어
`P5_101_카테고리매핑_필터세부설정/data/market_categories_cache.json`
(964KB)로 저장하고 **이번 커밋에 포함**했다. 이제 엑셀 파일이 없는
환경에서도 이 캐시로 매핑 작업을 계속할 수 있다.
