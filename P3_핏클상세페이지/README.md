# P3_핏클상세페이지

FitCL(핏클) AI 모델사진변경과 연동하여 **모델컷 10장** + **상품 디테일컷 5장**을 추출합니다.

## 입력

| 항목 | 설명 |
|------|------|
| 1. 소싱상품 | 의류 이미지 파일 (판매 상품 사진) |
| 2. 사진모델 | FitCL 모델 라인업에서 선택 |
| 3. 모델포즈 | **정확히 10개** 포즈 선택 (포즈당 모델컷 1장) |

## 출력

- `output/<상품명>_<시각>/model/` — 모델컷 10장
- `output/<상품명>_<시각>/detail/` — 디테일컷 5장

## 사전 준비

1. Chrome 디버그 모드 실행 (P2와 동일 — `P2/collect.py` 가 사용하는 CDP 9222)
2. Chrome에서 [fitcl.ai](https://fitcl.ai/) 로그인 후 작업 화면 열기

## CLI

```powershell
python fitcl_detail.py --product "D:\images\top.jpg" --model "모델_01_20대_여성_슬림" ^
  --poses "포즈_01_정면_전신,포즈_02_정면_상반신,포즈_03_측면_전신,포즈_04_측면_상반신,포즈_05_후면_전신,포즈_06_걷기_전신,포즈_07_앉기_전신,포즈_08_손주머니_상반신,포즈_09_팔짱_상반신,포즈_10_스냅_전신"
```
