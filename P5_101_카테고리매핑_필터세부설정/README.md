# P5_101_카테고리매핑_필터세부설정

검색필터 목록에서 **체크된 행**마다 마켓 카테고리를 자동 매핑합니다.

## 초기 진입 URL

```
https://tmg1898.cafe24.com/mall/admin/admin_group.php?pmode=filter_delete&...&ft_num=10&ft_sort=modify_asc
```

## 적용 범위 (요건)

| 항목 | 값 |
|------|-----|
| 수집사이트 | **musinsa.com 한정** — 다른 사이트는 검증 완료 후 개방 (선택 시 실행 거부) |
| 작업 대상 | **[선택조건으로 검색하기] 결과 목록** — 체크 여부와 무관하게 행 범위로만 지정 |
| 작업 행 범위 | **[부터] ~ [까지]** — 「목록 URL」 검색결과의 행 번호 기준 (1부터, 양끝 포함 · 기본 **1 ~ 5**) |

## 몇 번째 행인지 확인

작업 행 범위(예: 11행)가 실제로 어느 행인지 미리 확인하려면 보드
**[행 목록 확인]** 을 누르세요. 매핑 없이 목록만 열어 위에서부터 번호를 매기고,
지정한 범위에 `★` 를 붙여 로그로 보여줍니다.

```
검색 결과 782행 (위에서부터 1행)
    10행: ftid=770 · 필터=아름트리-무신사-남성-모자-캡
★ 11행: ftid=782 · 필터=아름트리-무신사-여성-신발-샌들/슬리퍼
    12행: ftid=790 · 필터=아름트리-무신사-여성-신발-부츠
```

번호는 화면에서 **[설정수정]**(`market_mapping_new`) 링크가 위에서부터 몇 번째로
나오는지로 정해집니다 — 표의 시각적 행 순서와 같습니다. CLI 는
`python map_categories.py --list-rows --row-from 11 --row-to 11`.

## 카테고리 구분 (11번가 · 롯데ON)

두 마켓은 구분 라디오가 있고 목록이 서로 다릅니다. 보드에서 어느 쪽을 매핑할지 고릅니다.

| 마켓 | 구분 | 기본 |
|------|------|------|
| 11번가 | 해외카테고리 / 국내카테고리 / **둘다** | 둘다 |
| 롯데ON | 해외직구 카테고리 / 일반카테고리 / **둘다** | 둘다 |

`둘다` 면 한 행에서 두 구분을 **각각** 매핑합니다. 라디오는
`input[name="openmarket_seller_type2_<코드>"]` 를 라벨 텍스트로 찾아 클릭하고,
`change_category_list(...)` 가 목록을 바꾼 뒤 매핑합니다.
CLI 는 `--variant 11ST=국내카테고리 --variant LTON=둘다`.

## 상품고시정보 팝업 대응

매핑 후 **상품고시정보 팝업**(`#mapping_notify_<코드>`)이 뜨면, 그 카테고리는 쓸 수 없다는
뜻이므로 다음 순서로 처리합니다.

1. 팝업을 닫는다 (`show_hide('#mapping_notify_<코드>')`, 실패 시 강제 숨김)
2. **직전 카테고리를 제외**하고 다음 최적 카테고리로 다시 매핑한다
3. [검색필터 설정저장] 을 클릭한다

최대 3회까지 다른 카테고리로 재시도하고, 그래도 팝업이 계속 뜨면 그 마켓은 넘어갑니다.

5. **[검색필터 설정저장]** → 다음 마켓

### 최적 카테고리 선정 (`matching.py`)

**필터명 해석** — `아름트리-무신사-남성-모자-버킷/사파리 햇`

| 조각 | 값 |
|------|-----|
| 무시 | `아름트리` · `무신사` (앞 2조각) |
| 상위 | `남성` (+ 보조: 패션잡화 · 의류잡화 · 패션의류잡화) |
| 중위 | `모자` (동의어: 소품 ↔ 잡화) |
| 하위 | `버킷햇` · `버킷` · `햇` · `사파리` (붙인말·토큰·반쪽 전개) |

`바라클라바` → `바라클라바` · `바라` · `클라바`,
`선글라스/안경테` → `선글라스` · `안경테` 처럼 전개합니다.

**찾는 순서**

1. 망고 단계수 == 엑셀 단계수 → 상위·중위·하위를 **단계 순서대로** 대조
2. 단계수가 다르면
   - 2-1) 상위가 있는 목록(없으면 중위 목록) → 중위로 좁히고(없으면 하위) → 하위에서 선택
   - 2-2) 못 찾으면 **중위 이름으로 전체** 재검색
   - 2-3) 못 찾으면 **하위 이름으로 전체** 재검색
   - 2-4) 그래도 없으면 **품목별 포괄 카테고리**
     · 의류 → 패션잡화 · 의류잡화 · 패션의류잡화
     · 신발 → 신발잡화 · 의류잡화 · 패션의류잡화
     · 선글라스/안경테/모자/햇/손수건/비니 → 의류잡화 · 패션의류잡화

같은 후보가 여럿이면 **일치한 조각이 많고 경로가 짧은** 쪽을 고릅니다. 어느 단계에서
찾았는지는 실행로그에 `[2-1) 상위 → 중위 → 하위]` 처럼 남습니다.

### 3) 최근접 지정 — 반드시 하나

위 순서로도 못 찾으면 **빈손으로 두지 않고 가장 가까운 카테고리 하나를 지정**합니다.
필터명에서 소재(가죽·니트·데님…), 용도/활용(등산·스포츠·방한…), 성별(남성·여성·공용)을
읽어 카테고리 경로와 대조하고, 글자 단위 유사도까지 합산해 최고점을 고릅니다.
성별이 다르면 감점하고, 품목 성격에 맞는 포괄 카테고리에는 가점합니다.
로그에는 `[3) 최근접 지정 (0.42)]` 로 남습니다.

### 반드시 지키는 선택 규칙

| # | 규칙 | 구현 |
|---|------|------|
| 1 | 최적 카테고리는 **엑셀 범위 안**에서만 | 확정 후 검사·교정 (아래 「엑셀 범위 보장」) |
| 2 | 필터명에 **남성/여성** 이 있으면 그 성별 안에서만. **반대 성별 용어가 든 카테고리는 절대 선택 금지** | 반대 성별(남성패션·남성신발·여성패션…) 경로를 후보에서 **완전 제거**한 뒤 탐색. 같은 성별이 없으면 무성별 경로에서 선택 |
| 3 | 필터명이 **의류·잡화·모자·선글라스·액세서리·신발** 이면 그 명칭이 있는 카테고리에서만, **상위 → 중위 → 하위** 우선 | 품목명이 나오는 단계가 얕을수록 우선 정렬 |
| 4 | **의류**는 패션의류잡화 · 패션의류 · 남성/여성(패션)의류 를 우선 | 우선순위 목록 순서대로 먼저 걸리는 그룹만 남김 |

예) `남성-팬츠` 에서 후보가 `패션의류 > 남성 > 하의 > 팬츠` 와
`스포츠/레저 > 등산 > 등산바지` 라면 **패션의류** 쪽을 고릅니다.

적용된 규칙은 로그 단계 표기 뒤에 `[성별=남성 · 품목=의류]` 처럼 남습니다.

### 품목 계열 배타

계열이 다른 카테고리는 고르지 않습니다. 의류 필터가 신발을, 신발 필터가 의류를,
선글라스 필터가 시계를 고르는 일이 없습니다.

| 계열 | 대표어 |
|------|--------|
| 의류 | 의류·상의·하의·아우터·팬츠·티셔츠·니트·코트·원피스 |
| 신발 | 신발·슈즈·운동화·스니커즈·구두·부츠·샌들 |
| 모자 | 모자·캡·비니·버킷햇·방한모 |
| 선글라스 | 선글라스·안경·아이웨어 |
| 시계 | 시계·워치 |
| 가방 | 가방·백팩·지갑 |
| 액세서리 | 액세서리·주얼리·목걸이·귀걸이·반지 |

계열이 드러나지 않는 경로와 **잡화 계열**(잡화·소품·패션잡화·의류잡화·패션의류잡화)은
남겨둡니다. 같은 계열이 하나도 없으면 그 잡화 계열에서 고릅니다.

### 전체 재검색 순서 — 하위 1차, 중위 2차

상위·중위·하위로 좁히지 못하면 **하위 이름으로 전체를 먼저** 훑고(동의어 포함),
그래도 없으면 **중위 이름으로 전체**, 마지막으로 포괄·최근접으로 갑니다.

### 반대 성별 절대 배제

여성 필터면 `남성…`, 남성 필터면 `여성…` 이 들어간 카테고리는 **어떤 단계에서도**
선택되지 않습니다. 후보 목록에서 아예 빼고 시작하며, 최근접 지정 단계에도 적용됩니다.
최종 선택 직전에 한 번 더 검사해, 위반 값이면 배제 후 재선정합니다
(로그: `반대 성별 카테고리 배제 → 재선정`).

반대 성별만 존재해 고를 것이 없으면 **그 마켓은 매핑하지 않습니다** — 잘못된 성별로
저장하는 것보다 비워두는 편이 안전하기 때문입니다
(로그: `성별(여성) 조건에 맞는 카테고리 없음`).

### 엑셀 범위 보장 (중요)

최적 카테고리는 **반드시 로드한 엑셀 목록 안의 값**에서 고릅니다. 어떤 경로로
찾았든(1·2-x·3 최근접) 결과가 목록 밖이면 목록 안의 가장 가까운 값으로 교정하고
로그에 `엑셀 범위 밖 → 목록 내 값으로 교정` 을 남깁니다. 화면 검색 결과에서 항목을
고를 때도 **엑셀 카테고리를 기준**으로 맞춥니다 (필터명 기준 아님).

### 동의어 보정

필터명과 마켓 카테고리의 표현 차이를 사전으로 메웁니다 — 바라클라바↔방한모,
버킷햇↔벙거지, 비니↔니트모자, 스니커즈↔운동화, 선글라스↔아이웨어, 목도리↔머플러 등.

### 저장 후 재검증 (미매핑 방지)

행의 6개 마켓을 매핑하고 [검색필터 설정저장] 을 누른 뒤, 화면의 hidden 값
(`openmarket_cm_category_<코드>` · `openmarket_cm_category_name_<코드>`) 을 읽어
**실제로 매핑됐는지 재검증**합니다. 비어 있는 마켓이 있으면 그 마켓만 다시 매핑하고
저장하며, 이를 **최대 3회** 반복합니다. 3회 후에도 남으면 로그에 경고로 남기고
결과에 `unmapped` 로 기록합니다.

### 실패 시 재시도

검색 결과가 없거나 목록 선택이 실패하면 **다른 카테고리로 최대 3회** 더 시도합니다
(매번 직전 후보 제외). 3회 후에도 안 되면 그 마켓만 실패로 남기고, 행 끝에서
[검색필터 설정저장 (Alt+S)] 을 눌러 마무리합니다.

검색어는 카테고리의 **마지막 단계**만 넣고, 결과 목록에서는 완전일치 → 리프일치 →
최고 유사도 순으로 고릅니다.

## CLI

```powershell
python map_categories.py --excel-dir D:\카테고리엑셀                    # 1~5행
python map_categories.py --excel-dir D:\카테고리엑셀 --row-from 6 --row-to 10
python map_categories.py --site-id MUSINSA.com --excel AUC20=D:\옥션.xlsx
python map_categories.py --markets AUC20,COUP
python map_categories.py --excel-dir D:\카테고리엑셀 --dry-run "남성 비니,여성 캡모자"
```

`--excel-dir` 는 파일명으로 마켓을 자동 인식합니다 (P5 출력 `카테고리분류표_옥션2.0_*.xlsx`).
`--dry-run` 은 브라우저 없이 매칭 결과만 출력합니다.
