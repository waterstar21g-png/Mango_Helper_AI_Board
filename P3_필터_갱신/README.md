# P3_필터_갱신

더망고 **검색필터(저장조건)** 화면에서 엑셀의 상품수집가능개수를 기준으로
**저장상품수**를 갱신합니다.

## 보드

좌측 **P3_필터_갱신** — UI는 P2와 유사. 엑셀 선택 → **더망고 URL**(고정 초기값) 확인 →
**작업시작**을 누르면 아래 로직 순서로 진행합니다.

## 프로그램 로직 순서 및 단계 (실행 로그는 이 1)~7) 단계만 표시)

1. 망고 수집 URL 링크로 진입한다 (입력 항목 정보로 제공).
2. 망고에서 한 개의 행 "URL"을 클릭한 후 → 이를 KEY로 엑셀자료 정보를 읽어온다.
3. 망고의 필터와 엑셀의 필터가 일치하지 않으면 다음 행으로 계속 진행한다.
4. 망고 행의 URL을 클릭 → 해당 페이지에서 "상품노출수(카드수)"를 추출한다
   (TOP→DOWN 스크롤 후 푸터영역→UP 방향으로 카운트, 엑셀자료와 비교하여 로그에 남김).
5. 망고 행에서 LABEL "수집조건수정" 버튼을 클릭한 후, 열리는 팝업창의
   "저장상품수" → "검색결과 상위 [ ]개만 상품만 저장" 필드에 (엑셀의 상품수 기준) 값을
   입력하고 하단 LABEL "저장하기" 버튼을 클릭한다.
6. 이후 팝업되는 "수정되었습니다" 메세지 하단의 LABEL "확인" 버튼을 클릭한다.
7. 2~6단계를 다음 행에 대해 반복한다.

버튼 클릭은 좌표 추정이 아니라, LABEL 텍스트로 찾은 **실제 DOM 버튼 요소**를 직접
클릭합니다 (href 재시도 없음). "저장하기"·"확인" 버튼은 팝업이 별도 창/프레임에
열려도 그 창을 찾아 클릭합니다.

## 저장상품수 규칙

| 상품수집가능개수 | 저장상품수 |
|------------------|------------|
| ≤ 200 | 그대로 |
| 201 ~ 500 | 300 |
| > 500 | 400 |
